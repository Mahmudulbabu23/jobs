Q1 Explain the concept of Inheritance in OOP. Name and briefly describe three common types. CB AP 2026
Answer
Inheritance is an OOP mechanism that allows a new class (child/derived) to acquire the properties and behaviours (fields and methods) of an existing class (parent/base), promoting code reuse and establishing an is-a relationship.

Three Common Types

  1. Single Inheritance — One child class inherits from exactly one parent class.
    Example: Dog extends Animal
  2. Multilevel Inheritance — A class inherits from a class that is itself a derived class, forming a chain.
    Example: Puppy → Dog → Animal
  3. Hierarchical Inheritance — Multiple child classes inherit from a single parent class.
    Example: Cat extends Animal AND Dog extends Animal

Other types include Multiple Inheritance (C++; one child, many parents) and Hybrid Inheritance (combination). Java avoids multiple inheritance of classes to prevent the Diamond Problem.

Q2 Describe step-by-step how Binary Search locates a target value in a sorted array. Why does it fail if the array is unsorted? CB AP 2026
Answer
  1. Set low = 0, high = n-1.
  2. Compute mid = (low + high) / 2.
  3. If arr[mid] == target → found, return index.
  4. If arr[mid] < target → search the right half: low = mid + 1.
  5. If arr[mid] > target → search the left half: high = mid - 1.
  6. Repeat steps 2–5 until low > high (not found).
Time Complexity: O(log n) — each step halves the search space.
Fails on unsorted arrays because the algorithm discards half the array based on the assumption that elements are ordered. If that assumption is violated, the target may be discarded in the rejected half, producing incorrect results.
int binarySearch(int arr[], int n, int target) {
    int low = 0, high = n - 1;
    while (low <= high) {
        int mid = (low + high) / 2;
        if (arr[mid] == target) return mid;
        else if (arr[mid] < target) low = mid + 1;
        else high = mid - 1;
    }
    return -1; // not found
}
Q3 Explain the logic to implement a Queue (FIFO) using two stacks. CB AP 2026
Answer

Use Stack S1 (input) and Stack S2 (output).

Enqueue (push to S1)

  1. Push element onto S1.

Dequeue (pop from S2)

  1. If S2 is empty, pop all elements from S1 and push them onto S2 (this reverses the order).
  2. Pop from S2 — this gives the oldest element (FIFO order).
Amortized time: O(1) per operation. Each element moves at most once S1→S2.
// Enqueue
push(S1, x);

// Dequeue
if (S2.empty())
    while (!S1.empty()) push(S2, pop(S1));
return pop(S2);
Q4 Explain the logic of Bubble Sort. Why is it inefficient for large datasets vs Merge Sort? CB AP 2026
Answer

Bubble Sort repeatedly steps through the array, comparing adjacent elements and swapping them if out of order. Each full pass "bubbles" the largest unsorted element to its correct position.

for (i = 0; i < n-1; i++)
    for (j = 0; j < n-i-1; j++)
        if (arr[j] > arr[j+1]) swap(arr[j], arr[j+1]);
AlgorithmBestAverageWorstSpace
Bubble SortO(n)O(n²)O(n²)O(1)
Merge SortO(n log n)O(n log n)O(n log n)O(n)
Bubble Sort does O(n²) comparisons and swaps even for nearly-sorted data. Merge Sort uses divide-and-conquer, always achieving O(n log n), making it far faster for large n.

Q6 Why might heuristic search (A*) be faster than blind search (BFS), even without guaranteed optimal path? CB AP 2026
Answer

BFS is an uninformed/blind search that explores all nodes at distance d before nodes at distance d+1, regardless of direction to the goal. It expands exponentially many nodes.

A* uses a heuristic function f(n) = g(n) + h(n) where g(n) is the cost so far and h(n) is the estimated remaining cost. This guides the search toward the goal, drastically reducing explored nodes.

AspectBFSA*
KnowledgeNone (blind)Heuristic estimate
Nodes expandedO(b^d)Much fewer (guided)
Optimal?Yes (unweighted)Yes if h is admissible
Speed in practiceSlow for large spacesVery fast with good h
Even a non-perfect heuristic greatly reduces search space. The trade-off is acceptable: a slightly suboptimal path found quickly is often more useful than the perfect path found slowly.

Q9 Write a C++ program to find the sum of the series: 1 + 2 + 4 + 7 + 11 + ... + N. CB AP 2024

The differences between terms are 1, 2, 3, 4, … (incrementing by 1 each time).

#include <iostream>
using namespace std;
int main() {
    int n, sum = 0, term = 1, diff = 1;
    cin >> n;
    while (term <= n) {
        sum += term;
        term += diff++;   // next diff: 1,2,3,4...
    }
    cout << "Sum = " << sum;
    return 0;
}
// For N=11: Sum = 1+2+4+7+11 = 25

Q14 Identify which methods overload, override and hide superclass methods in given Java code. BB AP 2023
Overloading: Same method name, different parameter list in the same class.
Overriding: Same method signature in a subclass; @Override; polymorphic at runtime.

Q17 Topological Sorting for DAG — write a C/C++ program. 6BFI AP 2021 
#include <iostream>
#include <vector>
#include <stack>
using namespace std;
int V = 6;
vector<int> adj[6];

void dfs(int v, bool visited[], stack<int> &stk) {
    visited[v] = true;
    for (int u : adj[v])
        if (!visited[u]) dfs(u, visited, stk);
    stk.push(v);
}

void topologicalSort() {
    stack<int> stk;
    bool visited[6] = {false};
    for (int i = 0; i < V; i++)
        if (!visited[i]) dfs(i, visited, stk);
    while (!stk.empty()) {
        cout << stk.top() << " ";
        stk.pop();
    }
}
Q18 Write a C/C++ program to check Balanced Parentheses in an expression. 6BFI AP 2021 
#include <iostream>
#include <stack>
#include <string>
using namespace std;

bool isBalanced(string expr) {
    stack<char> stk;
    for (char c : expr) {
        if (c=='('||c=='['||c=='{') stk.push(c);
        else if (c==')'||c==']'||c=='}') {
            if (stk.empty()) return false;
            char top = stk.top(); stk.pop();
            if ((c==')'&&top!='(')||(c==']'&&top!='[')||(c=='}'&&top!='{'))
                return false;
        }
    }
    return stk.empty();
}
int main() {
    cout << isBalanced("{[()]}") ? "Balanced" : "Not Balanced";
}
Q19 Write a C/C++ Program that shows whether the given sequence is a Mountain sequence or not. 6BFI AP 2021

A mountain sequence strictly increases then strictly decreases (peak not at start/end).

#include <iostream>
#include <vector>
using namespace std;
bool isMountain(vector<int> A) {
    int n = A.size(), i = 0;
    if (n < 3) return false;
    while (i < n-1 && A[i] < A[i+1]) i++;  // climb
    if (i == 0 || i == n-1) return false;  // peak at edge
    while (i < n-1 && A[i] > A[i+1]) i++;  // descend
    return i == n-1;
}
Q20 Given n jobs with starting times and durations, print maximum number of non-overlapping jobs. 6BFI AP 2021

This is the Activity Selection Problem. Strategy: sort by finish time (start + duration), greedily select jobs that don't overlap.

#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;
int maxJobs(vector<pair<int,int>> jobs) { // {start, finish}
    sort(jobs.begin(), jobs.end(), [](auto a, auto b){ return a.second < b.second; });
    int count = 0, lastEnd = -1;
    for (auto j : jobs)
        if (j.first >= lastEnd) { count++; lastEnd = j.second; }
    return count;
}

Q34 Apply IP addressing and routing: how packets are delivered using OSPF at the network layer. CB AP 2026

IP Addressing

Each device has a unique IP address (IPv4: 32-bit). Routers use subnet masks to determine if a destination is local or remote. Packets include source IP, destination IP, TTL, and payload.

OSPF (Open Shortest Path First)

OSPF is a link-state routing protocol using Dijkstra's algorithm to compute the shortest path tree. It operates at Layer 3 (Network Layer) and uses AS (Autonomous System) hierarchy with areas.
  1. Each router discovers neighbors via Hello packets.
  2. Routers exchange Link State Advertisements (LSAs) describing their connections and costs.
  3. Each router builds a complete Link State Database (LSDB) — identical across the area.
  4. Dijkstra's SPF algorithm computes the shortest path tree to all destinations.
  5. Results populate the routing table. Packets are forwarded hop-by-hop based on this table.
OSPF converges faster than distance-vector protocols (RIP) and scales well using hierarchical areas (Area 0 = backbone).
Q35 Explain the logic of a Checksum. How is it used to verify data integrity during file transfer? CB AP 2026
A Checksum is a fixed-size numeric value computed from data, used to detect errors introduced during transmission or storage.

How It Works

  1. Sender: Divides data into segments, adds all values (in binary), takes 1's complement → checksum.
  2. Checksum is appended to the data and sent.
  3. Receiver: Adds all received segments including the checksum.
  4. If result is all 1s → no error detected. If any 0 → error detected, request retransmission.
Sender: Data = [1001, 1010, 0011] Sum = 1001 + 1010 + 0011 = 11110 (overflow wrap) = 0000 Checksum = 1's complement of 0000 = 1111 Receiver: 1001 + 1010 + 0011 + 1111 = 11111 (wrap) = 1111 All 1s → Data OK ✓

Q39 Explain the Producer-Consumer problem. What synchronization issue must be solved? CB AP 2026
The Producer-Consumer problem involves two processes sharing a fixed-size buffer: the producer adds items, the consumer removes them.

Issues to Solve

  • Race Condition: Both access the buffer concurrently without synchronization, causing data corruption.
  • Buffer Full: Producer must wait when buffer is full.
  • Buffer Empty: Consumer must wait when buffer is empty.

Solution using Semaphores

Semaphore mutex = 1;    // mutual exclusion
Semaphore empty = N;    // free slots (initially N)
Semaphore full  = 0;    // filled slots

// Producer:
wait(empty); wait(mutex);
// add item
signal(mutex); signal(full);

// Consumer:
wait(full); wait(mutex);
// remove item
signal(mutex); signal(empty);
Q40 What is Multithreading? Why is it used? CB AP 2024

Q43 Short note on Virtual Memory and Cache Memory. SPCBL SAP 2022

Virtual Memory

A memory management technique that uses disk space (swap/page file) to extend the apparent RAM. Programs see a large contiguous virtual address space; OS maps it to physical memory using page tables. Enables running programs larger than physical RAM.

Cache Memory

A small, extremely fast memory (SRAM) between CPU and RAM. Stores frequently accessed data/instructions. Hierarchy: L1 (fastest, smallest, in-core) → L2 → L3 (largest, shared). Exploits locality of reference to reduce average access time.

Q44 You are designing a database for a Library. Explain the relationship between Book and Borrower tables. CB AP 2026

The relationship is Many-to-Many: a borrower can borrow many books, and a book can be borrowed by many borrowers (over time). This requires a junction/bridge table.

┌──────────────┐ ┌────────────────┐ ┌──────────────┐ │ BOOK │ │ BORROWING │ │ BORROWER │ │──────────────│ │────────────────│ │──────────────│ │ book_id (PK) │──────►│ book_id (FK) │◄──────│ bor_id (PK) │ │ title │ │ bor_id (FK) │ │ name │ │ author │ │ borrow_date │ │ email │ │ isbn │ │ return_date │ │ phone │ │ copies │ │ status │ │ address │ └──────────────┘ └────────────────┘ └──────────────┘
-- SQL Schema
CREATE TABLE Book (
    book_id INT PRIMARY KEY, title VARCHAR(200), author VARCHAR(100)
);
CREATE TABLE Borrower (
    bor_id INT PRIMARY KEY, name VARCHAR(100), email VARCHAR(100)
);
CREATE TABLE Borrowing (
    book_id INT REFERENCES Book(book_id),
    bor_id  INT REFERENCES Borrower(bor_id),
    borrow_date DATE, return_date DATE,
    PRIMARY KEY(book_id, bor_id, borrow_date)
);

Q48 What is DBMS? SPCBL SAP 2022
A Database Management System (DBMS) is software that enables creation, management, and querying of databases in an organized, efficient, and secure manner.

Key Features

  • Data Abstraction: Hides internal complexity from users.
  • Data Independence: Physical/logical changes don't affect applications.
  • ACID Transactions: Atomicity, Consistency, Isolation, Durability.
  • Concurrency Control: Multiple users access data simultaneously without conflicts.
  • Security: Access control, authentication, authorization.

Examples: MySQL, PostgreSQL, Oracle, MS SQL Server, MongoDB (NoSQL).

Q49 Describe a Man-in-the-Middle attack on the Diffie-Hellman key exchange protocol. BB AP 2023
Diffie-Hellman allows two parties to establish a shared secret over an insecure channel without exchanging the secret directly.

MitM Attack on DH

Alice Mallory (attacker) Bob │ │ │ │──── sends g^a mod p ──►│ │ │ │──── sends g^m mod p ─────►│ │ │◄─── sends g^b mod p ──────│ │◄─── sends g^m mod p ───│ │ Alice thinks shared secret = g^(a*m) mod p (with Mallory) Bob thinks shared secret = g^(b*m) mod p (with Mallory) Mallory decrypts, reads, re-encrypts — invisible to both!
Prevention: Authenticate the DH exchange using certificates (TLS uses this), digital signatures, or a PKI to verify parties' identities before key exchange.

Q51 If an attacker steals the private key of a website using TLS, what can be done with it? CB AP 2023

With the server's TLS private key, an attacker can:

  • Decrypt recorded past sessions (if Perfect Forward Secrecy was NOT used — static RSA key exchange). All captured traffic can be decrypted retroactively.
  • Impersonate the server — perform MitM attacks on future connections by presenting the real certificate and signing with the stolen key.
  • Forge signatures — authenticate as the server to clients.
If PFS (Perfect Forward Secrecy) was used (ECDHE/DHE cipher suites), past sessions remain safe because session keys were ephemeral and not derivable from the private key.
Response: Immediately revoke the certificate via the CA, issue a new key pair, enable PFS, investigate breach scope.
Q52 What is SQL Injection? How can it be prevented? SPCBL SAP 2022
SQL Injection is an attack where malicious SQL code is inserted into an input field to manipulate the database query.
// Vulnerable code:
query = "SELECT * FROM users WHERE user='" + input + "'";
// Attacker inputs: ' OR '1'='1
// Query becomes: SELECT * FROM users WHERE user='' OR '1'='1'
// Returns ALL users!

Prevention

  • Prepared Statements / Parameterized Queries (most effective)
  • Stored Procedures
  • Input Validation & Whitelisting
  • Least Privilege — DB user should have minimum permissions
  • WAF (Web Application Firewall)
// Safe parameterized query (Java):
PreparedStatement ps = conn.prepareStatement(
    "SELECT * FROM users WHERE user = ?");
ps.setString(1, input);
Q53 What is Cross Site Scripting (XSS) and how can it be fixed? SPCBL SAP 2022
XSS (Cross-Site Scripting) is an attack where an attacker injects malicious client-side scripts (JavaScript) into web pages viewed by other users.

Types

  • Stored XSS: Script persisted in DB (e.g., forum post).
  • Reflected XSS: Script in URL parameter, reflected in response.
  • DOM-based XSS: Client-side script manipulates DOM unsafely.

Prevention

  • Output Encoding/Escaping — encode < > & " before rendering
  • Content Security Policy (CSP) headers
  • Input Validation — reject or sanitize suspicious input
  • HttpOnly Cookie flag — prevents JS from accessing session cookies
  • Use secure frameworks (React auto-escapes JSX)

Q54 What is a Universal Gate? Prove that the NAND Gate is a Universal Gate. CB AP 2026
A Universal Gate is a gate that can implement any Boolean function without using any other gate type. Both NAND and NOR are universal gates.

Proof: NAND implements all basic gates

NOT gate using NAND: A ──┬──| NAND |── Ā └──| | AND gate using NAND: A ──| NAND |──| NAND |── A·B B ──| | (NOT of NAND output) OR gate using NAND (De Morgan): A ──| NAND |──┐ | NAND |── A+B B ──| NAND |──┘
Since NOT, AND, OR can all be built from NAND gates alone, and any Boolean function can be expressed using NOT/AND/OR → NAND is universal.

Q59 Max Heap Operations — show heap construction and operations. CB AP 2023

A Max Heap is a complete binary tree where each parent ≥ its children.

Build Max Heap from [4, 10, 3, 5, 1, 12, 8]

Initial Array: [4, 10, 3, 5, 1, 12, 8] Start heapify from last non-leaf (index 2): Step 1 — Heapify index 2 (value 3): 3 vs children 12,8 → swap with 12 [4, 10, 12, 5, 1, 3, 8] Step 2 — Heapify index 1 (value 10): 10 vs children 5,1 → no swap [4, 10, 12, 5, 1, 3, 8] Step 3 — Heapify index 0 (value 4): 4 vs children 10,12 → swap with 12 [12, 10, 4, 5, 1, 3, 8] Then heapify pushed 4 at index 2: 4 vs 3,8 → swap with 8 [12, 10, 8, 5, 1, 3, 4] Final Max Heap: 12 / \ 10 8 / \ / \ 5 1 3 4

Insert (e.g., 15): add at end, bubble up

[12, 10, 8, 5, 1, 3, 4, 15] → 15 > 5 swap → 15 > 10 swap → 15 > 12 swap Result: [15, 12, 8, 10, 1, 3, 4, 5]

Delete Max (extract root 15): swap root with last, heapify down

[5, 12, 8, 10, 1, 3, 4] → heapify 5 down → [12, 10, 8, 5, 1, 3, 4]
